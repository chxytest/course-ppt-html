# 确认节点 SOP · course-ppt-html

> 用途：把"需要用户给资料 / 拍板 / 修改"的节点前置成标准化流程，避免用户在半成品上反复救火。
> 用法：阶段0启动时把「资料准备清单」交给用户；每到一个确认门，用纯文本提问让用户签字，不确认不进下一阶段。

---

## 一、用户侧资料准备清单（G0 前置沟通用）

执行前请用户准备 / 确认以下资料，缺一项都可能造成返工：

| 类别 | 必填 | 可选 | 说明 |
|---|---|---|---|
| 主题与定位 | ✅ 主题、受众、演讲/阅读时长 | 副标题、口号 | 决定大纲方向 |
| 内容素材 | ✅ 核心观点 / 已有文章 / 大纲 | 案例、数据 | 阶段1 框架梳理依据 |
| 视觉风格 | ✅ 瑞士风 / 杂志风（二选一） | 主题色偏好 | 阶段3 deck 主题变量 |
| 个人 IP | ✅ IP 参考图（三视图或代表图） | 角色设定文档 | 阶段4 图生图锁人物基准 |
| 配图范围 | — | 指定哪几页要图 | 默认 4–8 张，先出 shot list |
| 视频范围 | — | 指定哪几页要视频 | 阶段5 范围 |
| 分发渠道 | — | 本地 / 云托管 | 影响外链处理 |

**G0 确认话术**：「以上资料齐备后告诉我"开始"，我进入框架梳理阶段。如果你已有完整大纲+素材，可跳过澄清直接开工。」

## 二、标准化确认门（G0–G6）

每到一个节点，向用户展示本阶段交付物 + 明确提问，等用户签字后再推进。

### G1 · 框架与内容确认
- **展示**：大纲 + 逐页「页码/标题/核心信息」表（不含视觉）。
- **提问**：「大纲和逐页核心信息 OK 吗？有要增删/调整的页吗？」
- **不确认不进**：阶段2 方案设计。

### G2 · 文档版方案确认
- **展示**：7 列逐页表（布局/配图/画板/讲稿）+ 配图 shot list（4–8 张，每张写清主题/结构类型/IP 动作/标注词）。
- **提问**：「逐页视觉规划和配图 shot list OK 吗？哪几页要配图、哪几页要画板、哪几页适合视频切片？」
- **不确认不进**：阶段3 HTML 生成。

### G3 · HTML 视觉定稿确认
- **展示**：本地预览链接（如 `http://localhost:8080/index.html`，或把 `index.html` 直接发用户打开）。
- **提问**：「风格/排版/动效 OK 吗？图片有没有被裁切、文字有没有错位？」
- **不确认不进**：阶段4 配图。

### G4 · 配图样张确认 ⭐
- **展示**：抽 2–4 张样张（如 P01/P02/P19），检查：人物跨图一致（脸/眼镜/发色/服装色）、零水印、字体合规、HTML 引用无缺失。
- **提问**：「人物形象一致吗？水印去干净了吗？字体对吗？」
- **不确认不进**：阶段5 视频。

### G5 · 视频范围与嵌入确认
- **展示**：已生成视频页清单 + 嵌入方式选项。
- **提问**：
  - 「哪些页要生成 3 秒微动视频？」（默认全部配图页，或用户指定子集）
  - 「嵌入方式：① 翻到即自动播放（推荐） ② 点击图才播放 ③ 仅生成视频文件不嵌入」
- **不确认不进**：阶段6 录制。

### G6 · 录制参数确认
- **展示**：录制方案说明（截图+合成法，因 headless 录不到 video）。
- **提问**：
  - 每页停留：视频页 4s / 静态页 3s（≤5s）是否符合？
  - 是否只录网页内容区（视口 1280×720，非全屏）？
  - 是否需要音轨（默认无音轨）？
- **不确认不交付**：`course-ppt-video.mp4`。

## 三、阶段性流程控制要点

1. **每阶段只做本层的事**：视觉没定稿不谈内容，内容没定稿不谈细节（分层审阅）。
2. **交付时标注层级**：回复开头写明"本轮属于阶段 X / 第 Y 层"，避免混层交付让用户反复切换视角。
3. **方案→实现对账**：阶段2 定的配图/画板/视频标记，阶段3 后做一次逐页 checklist 核销，不等用户发现漏项。
4. **补丁即欠账**：凡是需要"额外跑一个脚本"才能完成的流程，当轮回写主流程，否则下次必复发。
5. **待办带触发条件**：诊断中的"待深究/待确认"必须带责任归属和触发时机（如"下次同类任务前先查清"）。

## 四、快速确认话术模板

| 节点 | 一句话触发确认 |
|---|---|
| G1 | 「框架梳理完了，这是大纲和逐页核心信息，确认后我出文档版方案。」 |
| G2 | 「文档版方案（逐页表+配图 shot list）在这儿，确认后我开始生成 HTML。」 |
| G3 | 「HTML 出来了，本地预览已开，视觉定稿后我进配图。」 |
| G4 | 「配图样张在这儿，人物/水印/字体确认后我进视频。」 |
| G5 | 「视频范围和嵌入方式选一下，确认后我进整本录制。」 |
| G6 | 「录制参数确认下（停留/视口/音轨），确认后交付成片。」 |
