# 样例提示词参考 · course-ppt-html

> **用途**：编排各阶段的**真实用户样例提示词**，供你在生成前**按需展示给用户调优风格 / 角色 / 主题 / 动作**。
> **原则**：**不写死、不强制弹**。这些是「沟通调优的参考锚点」，不是默认定型配置。每次新项目都应让用户看样、改完再生成。
> **来源**：OPC HTML PPT 项目的真实聊天提示词（用户原文；`{ }` 内为原文占位符，使用时替换）。
> **维护**：若用户后续提供了某次项目的实际提示词原文，优先用原文替换对应段。

---

## 一、PPT + IP 配图 总调度提示词（对应阶段3 + 阶段4）

```text
{XXX.md}  结合附件内容，调用 /guizang-ppt-skill 制作完整PPT，使用小云雀CLI进行画图，通过 /ian-xiaohei-illustrations 提供画图风格逻辑，为每页幻灯片生成对应的3D转2D Q版风格配图，但是 IP 人物形象禁止修改。具体要求如下：

1. 根据附件内容自动规划PPT的整体结构，包括封面、目录、内容页和结尾页
2. 每页幻灯片的内容应简洁明了，文字精炼，重点突出
4. 确保整体视觉风格统一，排版美观，图文搭配协调
5. 输出可直接使用的完整PPT文件

请先分析附件内容，规划PPT页面结构，然后为每页生成对应的3D转2D Q版风格配图描述，最后输出完整PPT文件。
注意，生成图片时背景色需要与PPT的背景色风格保持完全一致，确保整体视觉风格和谐统一，但要确保 IP 人物形象和原始三视图的人物形象一致，禁止修改人物形象。请参考PPT的现有配色方案，包括主色调、渐变方向和透明度等细节，使生成的图片能够无缝融入PPT页面，避免出现色差或视觉割裂感。
```

- **对应阶段**：阶段3（guizang 视觉底座）+ 阶段4（ian IP 配图）联合调度。
- **展示时机**：进入阶段3/4 前，把这段展示给用户，确认三点 —— ① 风格（Q 版 3D 转 2D）② 配图背景与 PPT 背景同色（无缝融入）③ IP 人物一致性（禁止修改形象，图生图锁三视图）。
- **调优点**：`{XXX.md}` 换成实际资料；「Q 版」可改为用户偏好的比例；「背景同色」要求务必落到生图提示词里。

## 二、个人 IP 三视图提示词（对应阶段4 前置 · 角色资产）★可复用模板

```text
我想要生成我的个人IP角色的三视图（正面视图、侧面视图、背面视图），采用3D转2D的渲染风格。请根据以下要求提供完整的生成提示词：
1. **角色设定**：这是一个原创个人IP角色，需要保持三个视图之间的设计一致性，包括配色、服饰细节、比例关系等。
2. **视图布局**：三个视图水平排列在同一画面中，分别为正面全身视图、侧面全身视图（左或右）、背面全身视图，角色处于标准站姿。
3. **风格要求**：3D建模转2D风格，保留3D模型的立体感和光影层次，同时融合2D插画风格的线条感和色彩平涂效果，类似手办质感或赛璐璐3D渲染风格。
4. **背景**：使用简洁的纯色或浅色渐变背景，突出角色本身。
5. **输出格式**：提示词需包含角色描述、视图布局说明、风格关键词、光影与材质描述等关键部分，结构清晰，可直接用于AI图像生成工具。
```

- **对应阶段**：阶段4 前置 —— 先有 IP 三视图资产，才能图生图锁人物。
- **展示时机**：首次做个人 IP 项目、或用户还没有三视图时，展示并引导用户填自己的角色设定后生成。
- **用户备注**：「这份是 IP 三视图的提示词，你也保存一下」→ 作为可复用模板长期保留。
- **调优点**：角色设定 / 配色 / 比例按用户实际形象替换；保留「三视图水平排列 + 标准站姿 + 纯色浅渐变背景」约束。

## 三、文档版 PPT 方案提示词（对应阶段2）★可复用模板

```text
你先不要生成 HTML，也不要写 PPT 页面代码。

请先为我做一份“文档版 PPT 方案”，主题是：
{主题}

最终交付形式是文档，请规划：
1. 正文教程结构
2. HTML PPT 链接或附件放在哪里
3. 哪些地方需要可编辑画板
4. 哪些页面需要个人 IP 配图
5. 哪些页面适合导出成视频切片

请输出逐页表格：页码、页面标题、核心信息、建议布局、是否需要配图、是否需要画板、讲稿备注。
```

- **对应阶段**：阶段2 —— 先出文档方案对齐，再进 HTML 生成。
- **展示时机**：每个新项目进入阶段2 时，把模板发给用户填 `{主题}` 即可直接复用。
- **用户备注**：「这个是输出 PPT 的提示词模板，你记录一下。方便后续使用。」→ 作为可复用模板长期保留。
- **调优点**：逐页表格 **7 列固定**（页码 / 页面标题 / 核心信息 / 建议布局 / 是否需要配图 / 是否需要画板 / 讲稿备注）。

## 四、配图转视频提示词（对应阶段5）

```text
用小云雀cli 基于PPT中的配图生成 3 秒视频。 风格保持原图 只做轻微镜头推进和局部动作：角色做一个小动作，橙色主路径轻微流动，关键标注轻微出现。 不要改变角色形象，不要新增复杂背景，不要加入多余文字。
```

- **对应阶段**：阶段5 —— 把阶段4 的静态配图转成 3 秒微动视频，嵌回 HTML `<video>`。
- **展示时机**：进入阶段5 前，展示并确认视频约束：保持原图、仅轻微镜头推进 / 局部动作、不动人物、不加背景 / 文字。
- **调优点**：「3 秒」可按页调；「橙色主路径轻微流动」是 OPC 项目专属意象，新项目按实际主视觉改。

## 五、ian-xiaohei-illustrations 适配成自己 IP 形象的提示词（对应阶段4 风格迁移）

```text
请将 `ian-xiaohei-illustrations.git` 项目的插画风格修改为附件中所示的形象风格。具体要求如下：

1. **对照附件形象**：仔细分析附件中的角色设计，包括线条风格、配色方案、人物比例、表情特征等关键视觉元素。
2. **风格迁移**：将现有插画调整为与附件形象一致的画风，确保整体视觉效果统一。
3. **保持项目结构**：在修改插画风格的同时，不改变项目原有的目录结构和文件组织方式。
4. **一致性检查**：修改完成后，确保所有插画文件在风格上保持协调一致。
```

- **对应阶段**：阶段4 前置 / 定制 —— 把 ian 技能默认小黑形象替换成用户自己的 IP。
- **展示时机**：用户首次使用、且有自己的 IP 形象参考图时，展示并引导「对照附件形象做风格迁移、保持项目结构」。
- **调优点**：附件换成用户实际 IP 参考图；四条要求（对照形象 / 风格迁移 / 保持结构 / 一致性检查）通用。

## 六、使用纪律（维护者 / 编排器必读）

- 每次新项目：**展示对应阶段样例 → 用户改风格 / 角色 / 主题 → 确认 → 再调用技能生成**。绝不直接套用样例当默认。
- 样例中的 `{XXX.md}` / `{主题}` 是用户原文占位符，使用时替换为实际资料或主题。
- **人物一致性铁律**：IP 形象一律图生图 + 参考图（三视图）锁定，禁止凭空改形象（呼应样例一「IP 人物形象禁止修改」）。
- 带 ★ 标记的两段（三视图 / 文档版方案）是用户指定的**长期可复用模板**，不要因为某次项目定制而覆盖删除。
