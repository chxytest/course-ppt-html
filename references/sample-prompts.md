# 样例提示词参考 · course-ppt-html

> 用途：**阶段3（guizang 视觉）/ 阶段4（ian IP 配图）的样例提示词**，供编排器在生成前**按需展示给用户调优**。
> 设计原则：**不写死、不强制弹**。这些样例是「沟通调优的参考锚点」，不是默认定型配置——每次新项目都应让用户看样、改风格/角色/动作/标注后再生成。
> 用法：进入阶段3/4 时，把对应技能的样例发给用户看，问「风格/角色/动作对吗？要调哪里？」，用户确认或改完再调用技能生成。

## 一、guizang-ppt-skill · 样例（阶段3）

> 调用 `guizang-ppt-skill` 产出 HTML 视觉底座时，先和用户对齐「风格 + 主题色 + 版式偏好」。
> 下面是两类成熟风格的**描述样例**，作为和用户沟通的话术参考（非固定 prompt）。

### 风格 A · 瑞士国际主义（Swiss / International Typographic）

```
主题：瑞士国际主义（无衬线 + 网格 + 高对比色块）
配色：背景纯白 #FFFFFF；主文字近黑 #0A0A0A；
      高亮锚点克莱因蓝 IKB #002FA7；次级高亮柠檬黄 #FFD400 / 柠檬绿 #00C389 / 安全橙 #FF6B1A
版式：严格网格、左对齐标题、大留白、数据大字报、章节用色块幕封
动效：横翻页 0.6s ease、进入时元素轻微上浮
适用：科技 / 产品 / 方法论，强调理性与秩序
```

### 风格 B · 电子杂志 × 电子墨水（Editorial / E-ink）

```
主题：电子杂志风（衬线标题 + 流体背景 + 暖色调）
配色：背景暖纸 #F1F3F5；主文字深靛 #0A1F3D；
      高亮靛蓝瓷 #002FA7；次级安全橙 #E8552D
版式：衬线大标题、流体/渐变背景、图文混排、引言大字
动效：横翻页 + 背景缓慢流体位移、章节用半透明幕封
适用：人文 / 商业故事 / 个人 IP，强调质感与温度
```

> 📌 **沟通话术**：「这次用瑞士风还是杂志风？主题色要不要换？版式上有没有想强调的（数据 / 故事 / 个人 IP）？」
> 样例仅供对齐，最终以用户确认的风格描述为准。

## 二、ian-xiaohei-illustrations · 样例（阶段4）

> 调用 `ian-xiaohei-illustrations` 产出 IP 配图时，先和用户对齐「角色卡 + 分镜动作 + 标注词」。
> 下面是样例结构，作为和用户沟通的话术参考。

### 角色卡样例（图生图锁人物的基准）

```
【角色名】：<用户名>
【性别/年龄感】：30+ 偏少年的成熟男性
【发型发色】：黑色微烫短发
【眼镜】：方框黑框
【服装】：浅灰休闲西装 + 白衬衫 + 深蓝领带
【表情】：温和微笑
【比例】：卡通比例但腿不短（避免 Q 版头身比失衡）
【画风】：3D 转 2D 赛璐璐 / 手办质感，干净极简背景
```

### 单张配图提示词样例（文生图 / 图生图通用）

```
[角色卡关键特征复述]，
正在[动作/场景]，[画面核心隐喻/结构]，
[风格] 3D 转 2D 赛璐璐风格，干净极简，[背景色]纯色背景，柔和光影，
轻微镜头语言，构图留白充足，
ABSOLUTELY NO watermark, no signature, no text logo, no extra characters。
```

### 分镜动作样例（每张图各异，保持角色一致）

```
P01 主视觉：一人站在中央，周围环绕「写作/剪辑/运营/客服」四个半透明岗位剪影 → 表现"一人公司"
P03 能力环：角色站在三个重叠圆（写作×运营×产品）的交集处，手托发光核心 → 表现"稀缺能力交集"
P07 成长地图：角色沿一条橙色路径走过 8 个路标（学习→试点→...→规模化） → 表现"八阶段进阶"
P19 行动号召：角色举放大镜对准一个瓶颈节点，背景展开下一步箭头 → 表现"找到杠杆点"
```

> 📌 **沟通话术**：「角色卡这样对吗？哪几页要配图、各自什么动作/隐喻？标注词要不要加（如'稀缺能力交集'）？」
> 样例仅供对齐，最终以用户确认的角色卡 + 分镜为准；人物一致性一律走图生图 + 参考图锁定。
