## 一、生图链路（最高频 ⭐）

| 坑 | 现象 | 根因 | 修复 | 预防 |
|---|---|---|---|---|
| 生图不落本地 | HTML 显示占位「图消失」 | 平台落盘名是数字 ID，非 `pNN.jpeg` | 下载后强制 rename 对齐引用 | 🔴 铁律：每次生图必落 `assets/` 且文件名对齐 |
| 轮询误判失败 | 一提交即 FAIL，从不下载 | 空 error（=生成中）被当失败 | 只在真实 error 非空时判失败 | 轮询只看 `completed:true` + 真实 error |
| 旧图永不替换 | 改了图但 HTML 还是旧的 | 旧 skip 逻辑「本地有图就跳过」 | 重生成前先删旧图 | 批量重生成脚本默认先删旧 |
| 人物漂移 | 每图脸/发型都变 | 文生图无参考锁 | 图生图 + 参考图锁定 | IP 配图一律走图生图 |
| 水印残留 | 左上角"AI生成"水印 | 模型级行为，prompt 压不住 | 平台开去水印开关 + prompt 双保险 | 平台开关优先，prompt 辅助 |
| JSON 空格不兼容 | `--image` 后匹配全失败 | API 返回 key 后带空格 | `raw.replace(': ', ':')` 归一化 | 解析前先压缩空格 |
| rename 未触发 | 10 张全以数字 ID 名落盘 | 旧实现未执行 rename | 独立脚本按 mtime 映射补 rename | 🔴 必须固化回主脚本 |

**铁律记忆**：每次生成的图，必须立刻下载保存到项目本地 `assets/`，文件名与 HTML 引用严格对齐。绝不允许"图在平台、本地是旧的"。

## 二、HTML / CSS

| 坑 | 现象 | 根因 | 修复 |
|---|---|---|---|
| 图片被裁切 | 配图显示不完整 | `.frame-img` overflow:hidden + cover | 改 contain + height:auto + overflow:visible |
| 过渡页不居中 | 居中 style 不生效 | 内联 style 被缓存/覆盖 | 加 CSS `!important` 强制居中 |

**规律**：PPT 布局类修改，凡涉及"用户看到的视觉对齐"，优先用 CSS 规则而非内联 style。

## 三、视频生成 / 嵌入

| 坑 | 现象 | 根因 | 修复 |
|---|---|---|---|
| 参数缺失崩 | 批量 Exit 1 | 漏传 ratio/resolution/model | 补全视频必填参数 |
| 限频打断 | 多页漏生成 | `操作过于频繁` 无重试 | 指数退避重试（60/90/120/150s）+ 每页间隔 20s |
| 轮询超时 | 某页卡 5 分钟 | 上限 25 次不够 | 上限设 ≥40 次（8 分钟） |
| 嵌入不覆盖 | 新视频页不播 | syncVideos 非通用 | 用通用实现遍历每页 `.frame-img > video`，新增页无需改 JS |

## 四、整本录制（截图 + 合成法）

| 坑 | 现象 | 根因 | 修复 |
|---|---|---|---|
| headless 录不动 | 视频帧冻结 | Chromium 不合成 video 帧 | 改截图+合成法 |
| 坐标溢出 | 插图错位到屏外 | 动画未 settle 取坐标 | 截图前等 1.2s settle |
| 双重图像 | 两个并排角色 | 截图时 video poster 未隐藏 | 截图前 `visibility:hidden` |
| ffmpeg 损坏 | dyld libxcb 缺失 | 系统 ffmpeg 坏 | 用 `ffmpeg-static` 静态二进制（`npx ffmpeg-static` 或 pip 后取路径） |
| 尺寸误判 | 拉伸/黑边异常 | 假设 1280×720 | 探测真实分辨率算 contain |
| contain 算错 | 视频变形 | 假设 16:9 | 按真实比例 object-fit:contain 居中 |

**环境坑备忘**：
- `vNN.mp4` 真实尺寸**非** 1280×720（常见如 968×720、1256×720）→ 必须探测真实分辨率算 contain，不能假设。
- `vidsize` 正则别用 `Stream.*?Video.*?(\d+)x(\d+)`（误匹配 codec tag `0x31637661`）→ 用 `,\s*(\d{3,4})x(\d{3,4}),`
- ffmpeg 命令务必加 `-y`（否则 clip 已存在时卡在 Overwrite 提示导致进程挂死）；scale 尺寸取偶数。

## 五、协作 / 流程

| 坑 | 现象 | 根因 | 修复 |
|---|---|---|---|
| 方案→实现漏项 | 某页配图/画板都没做 | 无逐项对账 | 实现后逐页 checklist |
| 补丁绕过 | 同类问题反复 3 次 | 一次性脚本没固化 | 当轮回写主流程 |
| 待深究欠账 | 根因标注待查后搁置 | 无责任归属/触发时机 | 待办带触发条件 |
| 误报照做 | 为不存在的问题改 | 没先查证 | 先回溯方案原文再回复 |

## 六、方法论提炼（速记）

1. **分层审阅**：先视觉、后内容、再细节。每层不通过，下层不启动。交付时标注"本轮属哪一层"。
2. **生图落本地铁律（P0）**：每次必落 `assets/`，文件名对齐引用。
3. **一次性补丁 ≠ 修复**：需"额外跑脚本"才能完成的，必须当轮回写主流程。
4. **"待深究"= 欠账**：诊断日志的待办必须带责任归属和触发时机。
5. **方案→实现逐项对账**：配图/画板/视频标记逐页核销，不等用户发现。
6. **录制带 video 的页面**：headless 录不到，一律「截图+合成」。
