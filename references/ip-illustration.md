# IP 插画生成 · 提示词模板与多工具替代 · course-ppt-html

> 阶段4 依据。目标：为课程 PPT 生成**跨图一致、零水印**的个人 IP 形象配图。
> 本文件自包含——不依赖任何外部 skill，可直接照抄提示词到任意生图工具。

---

## 1. 核心原则（🔴 必读）

1. **一致性 > 花哨**：人物脸/发型/眼镜/服装颜色必须跨图锁定。纯文生图必漂移。
2. **一律走图生图（image-to-image）**：用一张角色参考图（三视图或代表图）作为基准，每次生图都带它。
3. **水印**：平台若提供"去除 AIGC 水印"开关，优先开；prompt 加 `ABSOLUTELY NO watermark, no signature, no text logo` 辅助。
4. **落本地铁律**：生成后**立即下载**到 `assets/`，文件名对齐 HTML 引用（如 `p03.jpeg`）。平台后台的图 ≠ 本地图。

---

## 2. 角色设定占位符（先和用户确认）

生成前，请用户提供（或用以下占位符起草后让用户改）：

```
【角色名】：汉堡
【性别/年龄感】：30+ 偏少年的成熟男性
【发型发色】：黑色微烫短发 / #1A1410
【眼镜】：方框黑框 / #1A1A1A
【服装】：浅灰休闲西装 #B8BCC2 + 白衬衫 + 深蓝领带 #1F3A6B
【表情】：温和微笑
【比例】：卡通比例但腿不短（避免 Q 版头身比失衡）
【画风】：3D 转 2D 赛璐璐 / 手办质感，干净极简背景
```

> 把上面固化为"角色卡"，后续每张图都在 prompt 里复述关键特征，保证一致。

## 3. 单张配图提示词模板（文生图 / 图生图通用）

```
[角色卡关键特征复述]，
正在[动作/场景]，[画面核心隐喻/结构]，
[风格] 3D 转 2D 赛璐璐风格，干净极简，[背景色]纯色背景，柔和光影，
轻微镜头语言，构图留白充足，
ABSOLUTELY NO watermark, no signature, no text logo, no extra characters。
```

示例（汉堡 IP 在"一人公司"页）：

```
30+ 偏少年的成熟男性，黑色微烫短发，方框黑框眼镜，浅灰休闲西装 + 白衬衫 + 深蓝领带，温和微笑，卡通比例但腿不短，
正站在一张桌子前同时操作显示器、接电话、打包货物，表现"一个人扮演多个岗位"，
3D 转 2D 赛璐璐风格，干净极简，#F1F3F5 纯色背景，柔和光影，
轻微广角，构图留白充足，
ABSOLUTELY NO watermark, no signature, no text logo, no extra characters。
```

图生图时：把角色参考图作为 `image` 输入，上面这段作为 `prompt`（或负向提示 `deviation from reference image` 防漂移）。

## 4. 多工具替代矩阵

| 工具 | 能力 | 一致性做法 | 备注 |
|---|---|---|---|
| **GPT-Image / DALL·E** | 文生图 + 图生图 | 上传参考图做 image-to-image；prompt 复述角色卡 | ChatGPT 用户首选 |
| **小云雀 / XYQ（即梦）** | 文生图 + 图生图 + 视频 | `--image` 图生图锁人物；CLI 取图后必 rename 落本地 | 见 SKILL 阶段4 铁律 |
| **Midjourney** | 文生图为主 | `--cref` 角色参考锁脸；`--cw` 控制角色权重 | 无原生图生图，靠 cref |
| **即梦 / 可灵** | 文生图 + 视频 | 参考图功能锁人物；视频用同参考图生成微动 | 国内可用 |

**负向提示词（通用）**：`watermark, signature, text logo, extra characters, multiple people, deformed, low quality, deviation from reference image`

## 5. 批量生成脚本要点（避免踩坑）

- **先删旧图再生成**（脚本默认 `rm` 旧 `pNN.*` 再跑），否则 skip 逻辑会让旧图永不被替换。
- **下载 rename**：平台 `query-result` 落盘名是数字 ID（如 `7671266971656536638.jpeg`），必须下载后 rename 为 `pNN.jpeg`。
- **轮询只在真实 error 非空时判失败**，否则等 `completed:true`。
- 解析 API 返回前先 `replace(': ', ':')` 归一化空格，避免 key 匹配失败。
